# Doddy — extra poses and expressions, V02

40 PNG files covering 72 new pose and expression studies, with a browsable gallery.

- 16 individual full-body poses, each supplied as an alpha PNG and an opaque warm-paper version.
- 4 pose sheets, 6 figures each: dance, small reactions, helpful actions, basketball.
- 4 expression sheets, 8 heads each: subtle social, comic, focus, quiet.

Individual poses include kneeling, tiptoeing, cross-legged sitting, leaning, reading on his belly, yawning/stretching, facepalming, fist-pumping, listening, balancing, reaching, sneaking, shrugging, shushing, holding an umbrella and dribbling a basketball.

## Use

Open `index.html` for the gallery and click any image for the original PNG. `manifest.json` gives dimensions, hashes, alpha status and source provenance. `GENERATION_PROMPTS.md` records the executed prompts.

These are AI-generated flat bitmap illustrations and animation references. The alpha cutouts retain a soft edge halo, even after a cleanup attempt; review them on your target background. The warm-paper versions provide a cleaner presentation alternative. The sheets are opaque. These files are not layered animation rigs or editable vector masters.

## Identity and provenance

Built with the built-in imagegen tool, using the original Doddy waving asset from the supplied V2 design/build pack and the first kit's turnaround as visual references. The circle head, ink stick limbs, cream mitten hands, oversized trainers and single eyebrow are retained. Original prompts supplied context for the character assets; this expansion follows the user's request for additional poses and expressions.

The V01 kit is preserved separately and unchanged. V02 was checked for PNG decoding, alpha presence on requested cutouts, file hashes and ZIP integrity. Visual review checks pose counts, layouts, background treatment and character consistency; it does not guarantee identical geometry across independent AI drawings.
