# Character assets for SwiftUI

Generated from the SVGs supplied in Interface v1.2. Contains 60 PNG files for light and dark appearances at @2x and @3x (each pose has a named `.imageset`). Copy chosen imagesets into your Xcode `.xcassets` folder after visual/provenance review, not the entire folder blindly.

Use via e.g. `Image("Doddy_listening")`, `Image("Doddy_memory_card")`. The system chooses variants from the luminosity appearance. Art is transparent. Native scaling/VoiceOver and animation still require implementation. No font binaries are included.
