## Brand gaps and precedence

- The complete base v1.3 pack/deck is not in this refinement subset. Referenced `base_file` paths do not prove those files were supplied.
- Standalone approved logo master, app icon, native vector/raster export specifications, complete token system and approved native state-art mapping remain inputs to confirm before integration.
- The Character Bible adds proposed acting/personality rules; it does not define character appearance or grant rights to third-party marks.
- New listening/speaking/error performances would require approved rigging or masters. This prototype uses existing static art and explicitly staged states.
- Export-pixel dimensions, CSS sizing and SVG viewBox values do not establish native point sizes.
- Fonts carry the bundled SIL OFL; comply with those licenses. Character provenance is the supplied user's pack; this study is not an independent legal-rights audit.
- Later user-supplied visual rules override proposed interface roles and copy. Record a discrepancy before changing an existing master.
