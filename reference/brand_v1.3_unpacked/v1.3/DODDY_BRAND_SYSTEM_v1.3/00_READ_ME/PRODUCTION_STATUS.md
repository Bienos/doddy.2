## Not yet production-final

1. Wordmark uses a font-based SVG text treatment, not custom drawn/outlines; create a bespoke outlined version and seek trademark clearance.
2. Motion GIFs are demonstrations only - no production Rive/Lottie rig in this pack.
3. This brand system derives from earlier approved illustration *direction*, not an exact trace of the earlier raster drawings; a human illustrator should approve final character fidelity.
4. App screens and widgets are speculative design mockups. Platform-specific interactions, final accessibility and feature viability must be independently tested.
5. PDF/PPTX uses editable slide text and slide-level shapes, but character art is embedded as imagery. Edit actual SVG files for character illustration changes.
6. The professional colour palette separates decorative Doddy Orange (#FF6A00) from accessible small-copy orange (#A44200). Complete contrast testing remains part of UI implementation.
7. The pack provides candidate typography but does not include font binaries. Verify all type licenses and usage terms independently.
