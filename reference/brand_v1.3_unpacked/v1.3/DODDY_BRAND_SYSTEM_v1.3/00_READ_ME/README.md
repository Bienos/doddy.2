# DODDY Brand System v1.3

## What is included

A set of newly authored SVG vector character assets, 33 expression drawings, 28 pose drawings, four turnaround views, source logos, brand colours/tokens, motion previews, app/social templates, an editable PowerPoint-based guideline deck and its PDF export. The PDF/PPTX and image previews are generated from the documented system.

**Important limitations:** This pack is a usable art-direction/system v1.3, not a legally cleared trademark package or production character rig. The SVG wordmark uses Lobster Two text and must be converted to outlined paths/approved lettering before brand launch. App mockups are illustrative, not tested screens. Motion previews are storyboards/sampled GIFs, not deployed Lottie/Rive rigs. No proprietary fonts are included.

## Working source

- The master SVG is the canonical anatomy reference.
- Other expressions and poses are independent, editable vector compositions.
- The guideline presentation contains editable text/geometry; included illustrations are embedded previews. Edit original SVG files when changing the character.
- Brand token JSON is a reference starting point, not a validated design-token pipeline.

## Source attribution

Developed from the user's approved earlier Doddy concept direction and prior app design showcase. The reference showcase is not reproduced as source artwork in this pack. All new vector art is systematically constructed for v1.3.
