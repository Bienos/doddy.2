# Asset naming standard

- all lowercase ASCII, words separated by `_`
- expressions: `doddy_expression_<emotion>.svg`
- poses: `doddy_pose_<verb>.svg`
- icon: `doddy_app_icon_1024.png`
- app screens: `doddy_ui_<surface>_<mode>.svg`
- social templates: `doddy_social_<format>_<variant>.svg`
- motion preview: `doddy_motion_<state>.gif`

Provide a meaningful accessibility label for each visible character where its gesture conveys state. All animation loops should honor Reduce Motion and pause while offscreen.
