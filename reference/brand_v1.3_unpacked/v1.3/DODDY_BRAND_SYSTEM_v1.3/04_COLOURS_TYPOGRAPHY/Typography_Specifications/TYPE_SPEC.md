# Doddy typography - v1.3

- **Display/logo exploration:** Lobster Two Bold Italic, used selectively in headline treatments and wordmark exploration. The wordmark is not yet a trademark-cleared bespoke logotype.
- **Interface/body:** Inter, regular 400, medium 500, semibold 600, bold 700.
- **Handwritten supporting labels:** Comic Neue, limited to small friendly flourishes, not essential UI.

## Type scale

Display 64/68; H1 48/52; H2 34/40; H3 26/32; body 16/24; small 14/20; label 12/16 (px/line height). Avoid essential text below 14px in app.

## Font handoff

No font files are redistributed. Verify current license terms before public distribution. Fonts are examples, not modified copies of third-party typefaces.
