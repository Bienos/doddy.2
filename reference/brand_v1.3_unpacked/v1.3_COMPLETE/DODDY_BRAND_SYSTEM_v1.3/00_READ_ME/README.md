# Doddy — Brand System v1.3

**Your mate in your pocket.**

This pack continues the approved black-ink/orange character direction, using the recovered October 8 brand and app showcase boards as **reference material**. It contains original, newly authored editable SVG/PDF/PPTX and PNG artwork rather than extracted editable masters from a flattened showcase.

**Start here:** Open `01_BRAND_GUIDELINES/Doddy_Brand_Guidelines_v1.3.pdf`, followed by `03_CHARACTER/Master_Character`, `02_LOGOS`, and the token JSON in `10_DEVELOPER_HANDOFF`.

**Production integrity:** The SVG characters are actual drawn vector paths/shapes, while the illustrative wordmark uses editable SVG text (font substitution may change appearance); retained reference PNGs are raster. GIFs demonstrate two loops, not an extensive full character animation library. App screens are visual examples, not runnable iOS app components. The PPTX text and layout shapes are editable; character illustrations are included as embedded PNGs with their editable SVG sources supplied separately.

**Approval status:** This is a complete, usable **v1.3 production draft**, not independently approved final character master. Detailed illustrator review recommended before commercial asset freeze; the original approved showcase is a visual benchmark, not itself exportable source artwork.

**Licensing:** Vector assets newly generated for this package are provided for the Doddy project. Inter is a third-party open-source typeface—consult its SIL Open Font License separately. No font binaries included.
