# Doddy Typography

**Primary UI:** Inter Regular/Semibold/Bold, designed for readable functional interface text.

**Display:** Custom hand-inked Doddy lettering should be created as original outlines for final art. Current wordmark SVG is editable bold/italic type with orange underline; it is a production fallback, not a bespoke lettered master.

**Headline scale (responsive examples):** Display 60/62 at mobile hero, H1 40/44, H2 32/36, H3 24/30, body 16/24, label 13/18. Increase line spacing for longer copy.

**Do not use:** multiple conflicting handwritten fonts, overly compact interface labels or tiny captions below accessibility limits.

**Font rights:** Inter is SIL OFL; font binary is not included. Use licensing-compliant imports at implementation.
