## Conflicts and precedence
1. **iPhone vs Android:** latest owner direction is iPhone-first; archive's Android-first concept remains historical.
2. **General AI buddy vs first useful job:** character-wide promise supports the brand, but first build tests a narrow recurring job. Defer the agent platform until evidence supports expansion.
3. **Character-first launch vs utility-first build:** operate as two parallel experiments with separate success metrics; do not use character follower counts as app retention.
4. **Memory store:** `UserDefaults` is legacy demo persistence; propose a protected transactional local database before release. No automatic import of demo data into real customer storage.
5. **Product identity:** existing prototype docs call the app `Companion`; new V2 product name is DODDY; reference filenames remain unchanged.
6. **Old UI versus approved orange stick figure:** brand files are newer visual candidates; visual direction must be confirmed rather than mix old cream/mint pebble as primary.
7. **Feature scope:** 5 Oct memory pack and 8 Oct opportunity study both caution against claiming a completed general voice assistant. Begin with text memory and measured usefulness; build optional voice and one action in later gates.
8. **Brand v1.3 collision:** COMPLETE and non-COMPLETE packages have different expression counts and drawings; *neither* is automatically final.
