## Proposal: split `DECISIONS.md` (not done)

`DECISIONS.md` is 390 KB with 406 numbered rows, all from October 2026, so yearly files would be one file. Instead: `docs/decisions/ADR-0xx-0yy.md` by hundreds (001 to 099, 100 to 199, ...), and `DECISIONS.md` becomes a one-line-per-ADR index (number, title, status, link), generated by a small script with a CI check that the index and the ranges agree. Things that must change with it: `STATUS.md` ("Don't read DECISIONS.md whole … search it for an ADR number"), `scripts/test_ci_needs_mac.sh` (uses `DECISIONS.md` as a test path, so it needs another name), the `DECISIONS.md` links in `docs/` and in code comments (for example `project.yml` line 109), and the numbering note at the top of the file (numbers 217, 218 and 458 are used twice).
