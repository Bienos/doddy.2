# Doddy can tell roughly where the person is, by voice, so a look-up near them needs no city

- **Date:** 2026-11-14
- **Decided by:** owner. Asked, in a voice conversation, "Czy ty wiesz, gdzie ja teraz jestem?", Doddy kept asking which city. The owner said yes to: "With your consent (approximate position, never stored) Doddy would search 'near me' without asking for the city."
- **Status:** accepted; built on branch `claude/where-am-i-approximate-location` (the app half not compiled in that session; CI compiles it). The live agent waits for the owner (`docs/OWNER_QUEUE.md` 116).
- **Replaces:** nothing. Adds one look to decision `2026-11-11-asked-for-runs-at-once`.

## Why
The agent had no way to know where the person is. `find_places` told it "Ask which town if the user didn't say", `geocode_place` "otherwise ask which city", and the prompt said the same, so every "blisko mnie" or "tutaj" became a question. The app already reads one position when asked for a parking spot or a leave-by reminder (`PlaceLocation`, While Using the App only), so the permission and the guard rules (`scripts/check_forbidden_capabilities.sh`: no Always, no background location, CoreLocation only in `DoddyApp/Infrastructure/Connections`) are in place.

## Decision
- **A new phone tool, `where_am_i`,** with no parameters. The agent calls it when the person asks where they are, says near me / blisko mnie / w pobliżu / tutaj, or a look-up needs a place they didn't name; then it uses the area in `find_places` (near), `web_search` (the town in the words) or `get_weather` (the rounded position as latitude and longitude). It never reads the numbers aloud and never claims an address.
- **Asking:** it is a look at the person's own things and runs at once (`AskFirst.ownLooks`, `tools.json` `ask: runs_now`, `ConfirmationTiers` at once), like `read_calendar`. The consent is iOS's own location question, While Using the App, which the app shows the first time (`PlaceLocation.requestWhenInUse`) and only while Doddy is on screen: from the background iOS shows nothing and the wait would never end, so the agent hears "not asked" and asks for the town. No Connections switch of its own; Pause all stops it (Apple's geocoder is another service), and with the Face ID lock on and the iPhone locked it doesn't run (`ProtectedDataPolicy`, fail closed). Outside text can't change that: it only reads, and its result is not counted as outside text (the names come from Apple's geocoder, one short line each).
- **The reading:** one position with `desiredAccuracy = kCLLocationAccuracyKilometer` (`CLLocationManager.requestLocation`), waited for 8 s; if none comes, the last position iOS gave Doddy, but only if it is at most 10 minutes old, valid and sure to 10 km (`WhereAmI.isCurrent`, `WhereAmI.best`). Approximate Location (Precise off) is enough. Otherwise the agent hears "unknown" and asks which town: never an older position passed off as now.
- **What leaves the app:** the position rounded to two decimals (about 1.1 km north to south) goes to Apple's geocoder (`CLGeocoder.reverseGeocodeLocation`, 5 s), which names the district (`subLocality`), town (`locality`), region and country. The agent gets those names (between the data markers, each cut to one line of 80 characters), the rounded position, how sure (about 1 km, about 3 km…) and how old the reading is. The district is left out when the reading is less sure than 2 km. The reading itself never leaves the app.
- **What is kept:** the app keeps nothing of its own: no note, no file, no database row, no log line with a place or a coordinate. "What Doddy did" gets "Checked where you are" (Polish "Sprawdzono, gdzie jesteś", app Maps) with no detail, like `read_calendar`'s row. What Doddy says aloud about it ("around Mokotów") is part of the conversation like anything he says: kept on this iPhone only while Remember what we talked about is on, and in the transcript ElevenLabs keeps of every conversation. What leaves this iPhone says both.
- **States:** denied or restricted → "not allowed", with where to allow it (iPhone Settings, Doddy, Location, While Using the App); Location Services off → "unavailable"; the person said no to iOS's question → "not allowed"; no reading in time → "unknown" (with "open Doddy and ask again" when Doddy isn't on screen). Each tells the agent not to call it again by itself.
- **Disclosure:** the location permission text (`project.yml`, and its nine translations in `l10n/*_infoplist.json`) adds "and to find roughly which town and district you're in (to about a kilometre) when you ask Doddy where you are or for something near you; that area goes to ElevenLabs as part of the conversation". What leaves this iPhone has a row (`whereAmI`), and the app's privacy manifest declares Coarse Location (linked, app functionality). The privacy policy and the App Store answers are the owner's (`docs/OWNER_QUEUE.md` 116).

## Consequences
- The agent can answer "a pharmacy near me" in one go. The live agent gets nothing until the owner attaches the tool after a TestFlight build that answers it; until then it keeps asking for the city, and a build without the tool answers it as unsupported.
- Privacy: a coarse location now goes to ElevenLabs in the conversations where the person asks for it, and on into a search when Doddy uses it. Apple sees the rounded position, as it does for any reverse geocode. Nothing is tracked, and the app keeps no reading or place of its own.
- Deploy order: the backend's Logbook list names the tool (`backend/src/web/logbook.ts`), so `doddy` should be deployed before or with the build; an older server refuses a Logbook day that counts it.
- Apple moved reverse geocoding to MapKit in iOS 26 (`MKReverseGeocodingRequest`) and marks `CLGeocoder` deprecated there. It still works, and with the iOS 17 deployment target it shouldn't even warn, but that was not compiled in the session that wrote it. Moving to MapKit's API is a later change, once it can be compiled and tried.
- In the background (Doddy talking from the island with the iPhone in a pocket) iOS may give no position to a While-Using app; the agent then hears "unknown" and asks. Doddy never asks for Always.
- "What Doddy did" shows "Looked up" for a "not allowed" or "unknown" answer too, as it already does for steps and Apple Health; making lookups' refusals read "Didn't happen" is a separate change.
