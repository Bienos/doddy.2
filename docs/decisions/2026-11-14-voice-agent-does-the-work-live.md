# The voice agent finishes its look-ups and does trips and research in the conversation

- **Date:** 2026-11-14
- **Decided by:** owner ("Zrób wszystko", 14 Nov 2026, to the six-point plan in the session: look-ups finish while the user speaks; a smaller prompt patch, not the repo prompt; a live research tool; a smaller tool set; agent tests; Render logs)
- **Status:** steps 1, 2 and 5 applied to the live main agent on 14 Nov 2026 (`voice-agent/README.md`, entry of 14 Nov "look-ups finish"); step 3 in the pull request that adds this file; step 4 proposed below, not done
- **Replaces:** nothing. It narrows when `hand_over_errand` is used (decision `2026-11-10-cards-pop-up-and-results-in-messages` keeps its card and its result in Messages).

## Why
The owner: voice tools "work so-so": travel fails, and asked to plan a trip or look at the web Doddy says he can't. Read on 14 Nov 2026 from the live main agent (`agent_0501m4et27vyeawrwqfdxxfszfa6`), its conversations, tool executions and both Render services' logs (read only):
- **User speech abandons running tools.** Every tool had `interruption_mode: allow`, so anything said while a look-up ran (5 to 20 s) ended it with "Tool execution was abandoned due to user input". Of the 11 newest `ask_claude` calls, 6 ended this way, one failed and 4 worked. The weekend trip of 14 Nov (`conv_6201m7dd0yfde6ps8w6fsdsfjxdh`) ended when the user said "Exactly. Mhm." while `hand_over_errand` waited.
- **The live prompt asked before every trip.** "Talk or task" step 3 said to hand a task to the background after the line "Mam się tym zająć w tle i dać znać, jak będzie gotowe?", and `hand_over_errand`'s description said to "offer to look it up now, asking before each search" when it failed. Doddy said exactly that on 12 Nov (`conv_5701m76rbdgeea8ttj6z36208c8c`): "Mogę poszukać teraz tutaj, ale osobno przed każdym wyszukiwaniem."
- **In a conversation Doddy can't read a page.** `web_search` gives 5 snippets. Reading pages happens only in the background errand, behind a card, with the result later in Messages.
- **`find_flights` was never called** (0 executions since it was attached on 12 Nov): the live prompt didn't name it, sent travel to the background and listed "book flights" under what Doddy can't do.
- **Too much context, no thinking.** 119 tools and a 27,393-character prompt: about 46,000 input tokens on every turn (the conversations' own usage), on `gpt-6-luna` with reasoning effort `none`. Doddy sent a riddle, an ice-cream recipe and "what did I mean by this sentence" to `ask_claude` (4 to 20 s each).
- **Server failures.** `doddy`'s log, 14 Nov 16:09:18 UTC: `ask_claude_failed`, `malformed_provider_result` after 8.9 s. `ClaudeProvider.ask` sends `claude-sonnet-5-5` with `max_tokens` 900 and no `thinking`; that model then thinks adaptively at effort `high`, and a harder question can spend all 900 tokens thinking and return no text. `doddy-messaging`, 12 Nov 02:11 UTC: the errand POST never reached the server, which was waking up from hibernation on the free plan (paid since 14 Nov, `STATUS.md`). `doddy` itself is still on the free plan and sleeps after about 15 minutes, so the first look-up after a quiet spell waits for it to wake.

## Decision
1. **Look-ups finish.** A tool that runs at once and only reads (the 22 marked `x_doddy.while_running: "finish"` in `voice-agent/tools.json`: web, news, places, flights, deals, memory, calendar, email, Drive, Notion, Todoist reads, `ask_claude`, `make_document`, `look_at_screen`) runs to its end while the user talks (ElevenLabs `interruption_mode: disable_during_tool`), and what they said is transcribed into the next turn (turn setting `transcribe_on_disabled_interruptions: true`). A tool with a card keeps `allow`: the person must be able to talk to Doddy while a card waits. `scripts/voice_agent_spec.py` checks the rule, renders the setting and compares it with the live agent.
2. **Do it now, background only for a big job.** The live prompt's "Talk or task", travel line, example, "Knowledge and research" and "Unsupported" passages, and `hand_over_errand`'s description: no "Mam poszukać?"; a weekend, a day out or a trip is planned in the conversation with `find_places`, `web_search` and `find_flights`, two or three options and a pick; the background only for a full report, many sites, comparing many offers, or when asked, and then without a question first; a failed hand-over falls back to look-ups without asking before each. Ordinary questions are answered from Doddy's own knowledge; `ask_claude` only for long or careful writing. The repo's `instructions.md` says the same in its own passages.
3. **A live research tool, `research_now`** (pull request with this file): Doddy's server (`doddy`) asks Claude, with Anthropic's web search and web fetch, to read two or three pages and return a short spoken answer with the sites it used. Runs at once, like `web_search`; its result is outside content (decision `2026-11-14-untrusted-content-needs-a-tap`); its own daily limit; a 40 s server deadline. The same pull request makes `ask_claude` send effort `low` and `max_tokens` 4,000 and check `stop_reason`, so thinking can no longer leave it with no answer. The tool goes on the live agent only after `doddy` is deployed and an app build that answers it is on the phone (owner queue).
4. **A smaller tool set (proposed, not done).** Detaching tools would remove features. The way that keeps them: at `startConversation` the app sends ElevenLabs a `tool_ids` override with only the tools this person can use (no Outlook, Notion, Todoist or Google Calendar tools when that account isn't connected: 29 of the 38 account tools, about 5,300 of the roughly 37,700 tokens the tool definitions take in `tools.json`), with the agent allowing that override. It needs a change in `VoiceSessionController.swift` (one agent at a time), a check that ElevenLabs Swift SDK 3.3.1 sends a tool-id override, and the owner's word on the agent setting. Next pull request.
5. **Tests on the agent.** Five ElevenLabs tests made from the failing conversations (ids in `voice-agent/README.md`), run against the live version. They are not attached to the agent: attaching stages them in the same draft as an unpublished prompt rewrite from another session (below).

## Consequences
- While a look-up runs, the user can't stop it by talking; "stop" or a new request is answered when it ends (at most its timeout, 60 or 90 s). End on the screen still ends the conversation.
- More look-ups per conversation (each costs Doddy a Monid search, a Kiwi search or a Claude call); `research_now` costs more than `web_search` and has its own daily limit.
- `research_now` sends the person's question to Anthropic, which searches the web and fetches pages: the privacy texts in the app and `docs/legal/PRIVACY_POLICY_DRAFT.md` say so; the published policy is behind (owner queue 26).
- An unpublished draft of the live prompt exists on the main branch (28,202 characters, an ASK-01 rewrite for spoken yes, from another session). It is behind the branch tip now; publishing it means staging it again on top of version `agtvrsn_6401m7dqs20ff85aytdjxcy1vrh0`, or it would undo this prompt.
