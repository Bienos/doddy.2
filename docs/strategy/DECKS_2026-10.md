# Presentations by Doddy: proposal (25 Oct 2026)

Owner, 25 Oct 2026, after a deck made in Messages ("Warszawa.pptx"): "cool it makes presentations but can this also make presentations using Anthropic Sonnet models and create presentations available to open in a way designed for Apple but you can download to any format and some cool option to use Google pptx or sth show mock ups and what's skills we could use maybe Doddy branding for normal decks but…" (the message ends there).

**This is a proposal. Nothing in it is built** except what "Today" lists. Mockups: Design canvas "Doddy: talking strip and decks", boards 1 to 4 and "Deck styles".

## Today (read from the code, 25 Oct)

| Path | Who makes the file | What it is |
|---|---|---|
| Messages (ADR-606) and voice `make_document` (ADR-564) | **Claude Sonnet 5.5** (`DODDY_CLAUDE_MODEL`, default `claude-sonnet-5-5`) on Doddy's server, with Anthropic's own **`pptx` skill** in code execution (`backend/src/tools/claude.ts`) | A real .pptx, 6 to 12 slides. Kept 7 days on the server; opened from Files with Quick Look. |
| Voice `make_presentation` (ADR-567) | The iPhone itself (`PresentationFile` in DoddyCore) | A plain .pptx: title slide plus up to 15 text slides in Brand V2.2 colours, no pictures. Share sheet to Keynote, Files or a person. |

So "made with Sonnet" already holds for the Warszawa deck. What's missing: a choice of look, a viewer inside Doddy, formats other than .pptx, and Google Slides.

## Proposal

1. **One maker.** Voice decks also go to `make_document` (Sonnet 5.5 and skills) when the server answers; the on-iPhone writer stays as the offline fallback, labelled as the simple version.
2. **Styles, picked on the card** (board 1): **Doddy** (cream, ink, orange, a pose from the owner's pack on the title slide only), **Czysty** (white, no character, for work and school), **Nocny** (dark, for a big screen). `make_document` gains a strict `style` enum; the card shows the style, and the approval digest covers it (ASK-01). Which style is the default: **owner decides** (below).
3. **A custom skill, `doddy-decks`**, uploaded once with `POST /v1/skills` and sent next to Anthropic's `pptx` skill (`container.skills`, `type: "custom"`, up to 20 skills a request). It holds the three styles' layouts and colours (from `DoddyDesignTokens`), safe system fonts only (no font files, CLAUDE.md rule 7), the rule that Doddy art appears only in the Doddy style and only as the bundled `WholeDoddy_*` PNGs (never drawn or generated), slide-writing rules (one idea a slide, short text, speaker notes) and a QA step (render, check overflow). This is the same layering the `sliyd-pptx` skill uses on top of `pptx`. Upload is a server admin step with Doddy's key; the key stays on the server.
4. **Formats** (board 3): the same run writes **.pptx** and a **PDF**, plus **PNG** slide images and the slide text as Markdown. Keynote has no public file writer: Keynote opens the .pptx and saves .key, so "Keynote" in the sheet is "open in Keynote". Whether the code execution container can render .pptx to PDF/PNG (LibreOffice) is **not checked**; if it can't, the server converts after download.
5. **Google Slides:** upload the .pptx to the user's Drive asking Drive to convert it to Slides (`files.create` with the Slides MIME type). Needs Sign in with Google with the narrow `drive.file` scope: a new connection, a privacy row, and a card per upload. **Owner decides.**
6. **Viewer in Doddy** (boards 2 and 4): the PDF's pages shown as slides (PDFKit), a thumbnail grid, Present in landscape with swipe, speaker notes and AirPlay, Download opening board 3. Native, so it looks like iOS; the .pptx stays the editable file.

## Skills we could use

| Skill | Source | Use |
|---|---|---|
| `pptx` | Anthropic, pre-built | Already used: builds the deck. |
| `pdf` | Anthropic, pre-built | The PDF copy; reading a PDF the user gives as material. |
| `docx`, `xlsx` | Anthropic, pre-built | Already wired for documents and spreadsheets. |
| `doddy-decks` | Ours, custom (`/v1/skills`) | Styles, art rule, writing and QA rules (above). |
| `doddy-voice` (later) | Ours, custom | Brand V2.2's way of speaking for slide text and notes. |

Not used: the `sliyd-*` skills (another brand's guide; only their layering pattern is borrowed).

## Cost (rough, not measured)

Sonnet 5.5 is $2 in and $10 out per million tokens. A deck run with a few `pause_turn` rounds is perhaps 30,000 to 80,000 tokens in and 10,000 to 16,000 out, so roughly $0.15 to $0.35 plus code-execution time. Measure on ten real decks before setting a daily cap.

## Decisions needed (owner)

1. The three styles and their names; the default style.
2. Voice decks through the server (Sonnet) instead of on the iPhone.
3. Google Slides: yes or no (a new Google connection with `drive.file`).
4. PDF and PNG copies: made in the code execution run or on Doddy's server.
5. Keep made files longer than 7 days (durable storage is a later phase).

## Risks and privacy

- What goes to Anthropic: the title, the request and any material on the card, as today (ADR-564). Nothing else from memory unless the card shows it.
- "Done" only after the server returns the file and it is read back; a lost connection is "couldn't confirm", never "made" (constitution: `unknown` is not success).
- Doddy can't see what the user does in the share sheet or in Keynote: it never says a deck was opened, saved or sent.
