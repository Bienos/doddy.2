# Exported visuals, fonts and rights boundary

- This combined ZIP contains all **copyable source SVG illustrations** from interface v1.2 and generated transparent PNG light/dark assets in a native-compatible Xcode image catalog; **not** original proprietary source rigs or proof of licensed ownership.
- The original browser interface ZIP contained `Caveat.ttf` and `Inter.ttf`. **Neither font binary is redistributed in this consolidated ZIP.** SIL OFL notices are preserved. The browser prototype's CSS now uses OS/browser fallback stacks, so browser-rendered lettering may differ. The PNG screenshots are unchanged from the provided prototype and remain the best view of exact visual direction.
- If owner specifically licenses/acquires typography, configure it in the final Xcode app separately with verified license and dynamic-text fallback. Keep those font binaries out of this handoff.
- The original `design/interface-v1.2/docs/ASSET-MAP.md` and source manifest describe the **unmodified source ZIP**; see the new `design/interface-v1.2/MANIFEST.json` for distributed assets. `MANIFEST_ORIGINAL.json` retains historical hashes and paths.
- Generated imagesets are derived from identical supplied SVG drawings, not redrawn/newly approved art or a motion rig. Verify visual rendering before release and do not crop/stretch faces.
- The two brand v1.3 archives remain read-only reference; don't treat either as final until owner selection. Legal rights/trademark review is not represented as complete.
