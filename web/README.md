# Doddy Web

The browser workspace for the same Doddy account the iPhone uses (ADR-600, ADR-601): a sign-in code from the phone, or Apple or Google, which opens the iPhone's account for that same sign-in (`docs/decisions/2026-11-09-web-sign-in-same-account.md`). Built to `web/dist` and served by `backend/` on the same origin, so the session is an HttpOnly cookie and there is no CORS.

- How it works, how to run, test, deploy and roll back: `docs/platforms/web.md`.
- Why it is built this way and what comes next: `docs/architecture/WEB_AND_SHARED_PLATFORM.md`.
- Colours (the website's palette, `CandidateTokens.swift`), metrics, wordmark, Doddy's poses and the favicon are generated by `tools/gen_web_assets.py`; don't edit `src/styles/tokens.css` or `public/brand/` by hand. The look is the website's (ADR-594): `src/styles/app.css`, and `logbook.css` for Logbook.
- Logbook (ADR-602): `src/pages/LogbookPage.tsx` and `src/logbook/`; reads `GET /v1/web/logbook`; the iPhone sends one summary of counts a day, on by default (`IPHONE_SENDS_LOGBOOK` in `src/logbook/config.ts` is true; decision `2026-11-09-usage-counts-on-by-default`). `LOGBOOK_ENABLED` hides the page.
- Admin (`/admin`): the owner's dashboard, `src/pages/AdminPage.tsx`, `src/admin/` and `src/styles/admin.css`, its own code chunk. The server answers 404 to every account not in `DODDY_OWNER_ACCOUNTS` (`GET /v1/web/owner*`); `SUPABASE_SECRET_KEY` adds emails and join dates. Counts only.
- Chat (ADR-657, numbered 604 on its branch; `docs/product/WEB_CHAT.md`): `src/pages/ChatPage.tsx`, `src/chat/` and `src/styles/chat.css`; ChatGPT's layout in Doddy's colours, wired to `POST /v1/web/chat` and `GET /v1/web/chat/context`; chats kept in this browser only. It replaced Ask Doddy (`/ask` redirects).
- Memory (ADR-603): `src/pages/MemoryPage.tsx` and `src/memory/`; the iPhone's sending is written and compiles in the hosted Mac job, but hasn't run on a device, so `IPHONE_SYNCS_MEMORY` in `src/memory/config.ts` stays false: the page opens on "nothing is kept" and the menu says Soon. `MEMORY_ENABLED` hides it.
- Messages (`docs/implementation/MESSAGES_WEB_SYNC.md`): `src/pages/MessagesPage.tsx`; a read-only copy of the iPhone's Messages thread from `GET /v1/web/messages`. `IPHONE_SENDS_MESSAGES` in `src/messages/config.ts` stays false until an iPhone build sends it, so the menu says Soon.
- Every visible word is in `src/i18n/messages.ts` and, for Logbook, Memory and the chat, `src/i18n/logbookMessages.ts`, `memoryMessages.ts` and `chatMessages.ts` (Polish default, English).

```sh
npm ci
npm run typecheck && npm test   # unit tests against contracts/ fixtures
npm run build                   # web/dist
npm run e2e                     # needs backend/ built: real server + Chromium; GitHub's workflows don't run it
```
