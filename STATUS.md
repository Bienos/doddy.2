Doddy is a voice-first companion for iPhone and iPad. The Apple Watch app and the Mac menu bar prototype are **paused** (ADR-572). This page says what is true now, in one page. **Replace facts when they change; don't add dated log paragraphs.** What a pull request changed goes in `changes/` (see `changes/README.md`); the full log up to 7 Nov 2026 is in `docs/archive/STATUS-log-2026-10-08-to-2026-11-07.md`.

## Code
- **Default branch:** `main`. It is the only permanent branch; every change arrives by pull request. Agents squash-merge their own pull requests once `core`, `ios-build` and `sensitive-paths` are green (`AGENTS.md`, "Merging"). `sensitive-paths` runs its guard script from `main`, never from the pull request, and also covers lockfiles, CI scripts, agent settings and skills, `site/api/` and `server/voice-token/` (#408); tying the three checks to GitHub Actions in the live ruleset is owner queue 62.
- **CI:** `.github/workflows/ios.yml`. Pushes to `main` run every job, including the whole UI suite (ADR-765, ADR-811); pull requests run path-selected jobs and only the UI smoke classes. The Mac job (`ios-build`) may run 100 minutes; `Config/Package.resolved` pins the seven remote packages (GRDB 7.12.0 since #219). A UI test that failed only because the app wouldn't launch now runs once more on a restarted simulator (#433, `2026-11-13-ui-launch-retry`): that was the whole of the 13 Nov failure on `main` (run 43412113691, two launch failures); the one real UI-test failure before it, `MotionEvidenceTests.testHiddenPicturesLeaveNoGap`, was fixed by #412. ## What changed in the product since 7 Nov (from `main`, not on a device)
- **Doddy account required** (`2026-11-08-required-account`; `Config/Doddy-Info.plist` names the Supabase project, so every build asks). The welcome signs in with **Apple or Google**; email codes are hidden (`2026-11-09-email-sign-in-off-for-now`). Doddy Web: Apple or Google opens the same account as the iPhone, in a small window on a computer (#374). Your Doddy account is under Settings › About. Linking an iPhone's earlier data takes a one-time code the iPhone asks for itself (#383; an app build from before it can't link). A fresh install removes the sessions an earlier install left in the Keychain, so it asks to sign in again (#388).

The messaging server deletes phone-agent conversations and task-call records with the account (#385, migration 032). Signing out ends the iPhone's messaging device (`DELETE /v1/device`) and a late answer changes nothing (#279, audit of 9 Nov); local data belongs to the account that made it, and nothing of it is sent to another account (#390, `2026-11-12-local-data-owner`).

## Known problems
- **Security review, 12 Nov 2026** (read-only, not a penetration test; an artifact in the owner's account). Fixed in code since: deleting an account reports success only when each server confirmed (#391, #409), and it deletes the account's voice conversations (#425, #426, #445). Still open: old Supabase functions without sign-in run in the accounts project, one of them an open OpenAI proxy; the old Render copies above still run; notes stay on a shared iPhone after a sign-out, visible to whoever signs in next (nothing is sent to their account since #390; an erase button is still to come); about four accounts can use up the shared hourly voice limit (owner queue 56). The console steps are the owner's.
- **Google sign-in fails** with `redirect_uri_mismatch` until Supabase's callback is registered on the Google OAuth client (owner queue 25). Apple on the website needs owner queue 28.
- **No dollar spend limits** on Anthropic, OpenAI or Monid (owner queue 2, 13). The Anthropic key replaced on 9 Nov works on both services: decks completed on `doddy` on 12 and 13 Nov, and the leaflet catalog's scans read pages with it on `doddy-messaging` (owner queue 66).
- **No staging environment:** Debug, TestFlight and production builds all use the production servers and voice agent. The plan is Doddy Beta on staging (ADR-812, owner queue 59).
- **The published privacy policy and the App Store answers are out of date:** they say the app has no analytics and miss Logbook, Messages on by default, recaps, the screen look, radar alerts and price alerts, decks' Wikipedia reads, runs-at-once reads, Uber and flight passenger data, and, once #466 is deployed, the ledger of Claude calls (owner queue 7, 24, 26, 31 to 34, 37, 42, 43, 58, 98). `docs/legal/PRIVACY_POLICY_DRAFT.md` matches `main` (#399), with its `[CONFIRM]` points for the owner and a lawyer.
