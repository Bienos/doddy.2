**Ask Doddy fixed for everyone (same branch, ADR-587; on the default branch since the 23 Oct merge; deployed 22 Oct; not run against the real Anthropic API; superseded in the app by Messages, ADR-585 and ADR-586).** Typed questions did nothing because the app called a separate OpenAI gateway that has no environment variables on any host, and Settings wanted a gateway address and invite code nobody had. They now go to Doddy's own server (`POST /v1/assist`, Claude, `ANTHROPIC_API_KEY` that ADR-564 already uses): no address, no code. Every iPhone can ask (`DODDY_DEVICE_SIGNUP=open`: the first iPhone owns the server, any other gets a guest session that can ask questions and reach nothing else), with 50 questions per iPhone and 500 in total per day to bound the bill (about $0.04 a question at the very most). Google and Supabase sign-in are left alone, as the owner asked. **To turn it on:** set `DODDY_DEVICE_SIGNUP=open` on the live Render service `doddy` (it is `first-device` now), deploy this branch, then ask a question on a second iPhone and look at the Render log for the `assist` line (counts and tokens only). `render.yaml` already says `open`. The SwiftUI changes (Settings, Ask) are uncompiled until the hosted Mac job; nine languages got machine-drafted text for the new wording. **After the 23 Oct merge the app no longer calls `/v1/assist`:** Messages asks the messaging server instead; the route stays on `doddy`.

## How agents should read this repo
1. This page, then **only** the page for the platform you are working on, under `docs/platforms/`.
2. That page lists the folders and the status doc for each feature. Open those, not the whole tree.
3. **Don't read `DECISIONS.md` (about 770 lines) whole.** Search it for an ADR number: `grep -n "| 452 |" DECISIONS.md`.
4. Ignore `reference/`, which is historical.
5. Run `scripts/ci.sh --core-only` on Linux. App code needs a Mac with Xcode.
