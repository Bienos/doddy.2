# Post ideas

Rough order. Each one needs real evidence behind it before it is written.

1. **"Saved" has to mean saved.** How a memory is only confirmed after the write is read back,
   and why a draft survives a failed save. Evidence: `M1_STATUS.md`, ADR 026.
2. **Search that shows its work.** Lexical search with matched terms and source on every result,
   diacritic-insensitive so "lodz" finds "Łódź". Why no embeddings yet. Evidence: ADR 005, 027.
3. **Talking to Doddy (once it is tested on a phone).** Voice via ElevenLabs, the "Save this
   note?" card, and why the agent can only answer from what you saved. Write only after a real
   English + Polish conversation on an iPhone is recorded in `V1_VOICE_STATUS.md`.
4. **Drawing Doddy.** The stick figure with an orange backpack, and choosing between two brand
   drafts. Write after ADR 010 (brand master) is decided.
5. **Building with an AI coding agent and an honesty script.** `NOT RUN` as a feature; what the
   capability guard catches.
6. **Your data, your exit.** Export to JSON and plain text, delete-all, what stays in backups.
   Evidence: ADR 028, 030.
