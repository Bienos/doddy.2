Vercel no longer skips a project's changes when its last deployment is older than Vercel's shallow clone. The `ignoreCommand` in `site/`, `gateway/` and `server/voice-token/vercel.json` compared only the last commit in that case, so the site's changes from #271 (9 Nov 2026) were never built and www.doddy.lol still showed the page from #259 (8 Nov). Now it builds whenever the previous deployment's commit isn't in the clone. Tested by `scripts/test_vercel_ignore_command.sh` (21 cases, in the `checks` group; 6 fail against the old rule). Merging builds all three projects once, since their `vercel.json` changed; only the site has code changes waiting.
