The Mac job now caches the app's Swift packages (the checkouts and the binary frameworks, LiveKit's alone is several hundred MB) instead of downloading them from GitHub on every run. On 8 Nov 2026 a LiveKit release asset (`RustLiveKitFFI.xcframework.zip`) answered 504 for hours and no Mac build could start (runs 42465092351, 42465199294).
`.github/workflows/ios.yml` restores `~/Library/Developer/Xcode/DerivedData/Doddy-*/SourcePackages` before `scripts/ci.sh` and saves it afterwards, only when ci.sh wrote `build/packages-ok` (every package resolved), because a cache key can't be overwritten and a partial download must never be saved. The key is the hash of `project.yml` and `Config/Package.resolved`, with a prefix fallback.
