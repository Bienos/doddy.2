Messaging server: the device token of a Doddy account stops working after 60 days unseen or 180 days after it was issued (anonymous accounts never expire), and `POST /v1/accounts/sign-in` with the current device token returns a fresh token and its `expiresAt`; the old one works 5 minutes more so a lost answer doesn't sign the iPhone out. "Seen" is written at most once an hour. Migration `040_device_token_lifetimes.sql` adds three columns and sets every existing Doddy-account device to "seen and issued now", so nobody is cut off the day it ships. Settings `DEVICE_TOKEN_EXPIRY` (default on; `0` turns it off), `DEVICE_TOKEN_IDLE_DAYS` (60), `DEVICE_TOKEN_MAX_AGE_DAYS` (180), `DEVICE_TOKEN_OVERLAP_SECONDS` (300). Decision `2026-11-12-account-and-device-tokens` part (d), choices in `2026-11-14-messaging-token-expiry-defaults`.
On by default because the iPhone signs in again by itself after a refused token while the Doddy account is signed in (read in `ServerClient.swift` and `DoddyAccountApp.swift`; no app code changed here, not compiled, not run on a device); the first call after a refusal fails once on screens that don't retry. The app doesn't yet rotate a token ahead of its end (a later change). A push still goes to a device row whose token has run out, and `DELETE /v1/device` can't use a run-out token: left for a follow-up.
Ran: `scripts/ci.sh --only checks` and `--only messaging`, with `TEST_DATABASE_URL` on a disposable Postgres. Existing sign-in tests changed in two places on purpose: the answer now carries `expiresAt`, and a repeat sign-in with the iPhone's token is a rotation (a fresh token), no longer the same token.
Owner step: `doddy-messaging` has auto-deploy off, so none of this is live until it is deployed (the migration runs at start-up; the deploy also ships whatever else is on `main`). Rollback: revert the server and redeploy; the new columns stay and the earlier code ignores them (tokens rotated in the meantime keep working, since rotation only replaces `token_hash`). `DEVICE_TOKEN_EXPIRY=0` stops expiry without a code change.
