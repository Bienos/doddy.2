Translating talks to its own ElevenLabs agent, which has no tools at all (decision `2026-11-12-translator-agent`; owner: "agent nie powinien włączać żadnych funkcji podczas tłumaczenia"). A translator start asks the token server for `{"agent":"translator"}` (`VoiceAgentKind` in DoddyCore, `VoiceTokenWarmer.translatorToken`), and the server answers with the translator agent's token (`server/voice-token`, default id in the code, `ELEVENLABS_TRANSLATOR_AGENT_ID` overrides). Every other conversation is unchanged. "Stop translating" by voice is translated like any line; End on the screen ends it. `voice-agent/translator/` is the spec, checked by `voice_agent_spec.py --agent translator` (one agent id in the spec, the server and the app).
