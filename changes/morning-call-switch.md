Morning call switch: Settings › Phone calls › Doddy calls you › Morning call has a switch (owner, 15 Nov 2026). On opens a time picker (05:00 to 11:59, the iPhone's clock) and the days (every day, weekdays, weekend, ticked days), then the voice card's own view; only that card's button books it, with the same approval and endpoint as the voice card (`POST /v1/calls/morning`). A new time or days replaces the active one. Off stops it at once. The switch shows only the server's read-back, and is disabled with the reason when the server's morning calls are off, the number isn't verified or "Doddy may call me" is off. After a stopped booking (`already_done`) the app now uses a new idempotency key, so the same schedule can be set up again.
