Signing in no longer leaves the iPhone thinking Doddy's server "isn't set up for Doddy accounts". The saved account token runs out after about an hour; the launch check asked the server with it, got a 401, and remembered "not yet" (so Delete account refused). The link and the check now refresh the token first, and Delete account asks the server again before it says no. Without the refresh, a stale token would also have answered "nothing to link" and dropped an iPhone's earlier data silently.
